📋 Setup Instructions
  1. Run az login in your terminal to authenticate with Azure
  2. Go to Azure AI Foundry
  3. Create or select a project
  4. Go to Model catalog → Search for "whisper"
  5. Deploy the whisper model (OpenAI)
  6. Copy only the Target URI from the deployment
  7. Make sure your user has Cognitive Services User role on the resource
